# Промт для Claude: Автоматический сбор отзывов после визита

---

## СУТЬ ЗАДАЧИ

Клиент посещает кафе/делает заказ → через `{DELAY_HOURS}` часов ему автоматически
приходит сообщение в Telegram с просьбой оставить отзыв на 2ГИС и Google Maps.
Это поднимает рейтинг заведения в поиске без ручного труда администратора.

**Что генерирует Claude:**
- `review_bot.py` — готовый Telegram-бот на Python
- `requirements.txt` — зависимости
- `setup_guide.md` — инструкция за 5 шагов + тексты сообщений

---

## КАК ИСПОЛЬЗОВАТЬ

1. Заполни все `{ПЕРЕМЕННЫЕ}` данными клиента
2. Вставь **СИСТЕМНЫЙ ПРОМТ** в System Prompt
3. Отправь **ОСНОВНОЙ ПРОМТ** → получи три файла
4. Разверни бот на VPS или компьютере клиента

## СИСТЕМНЫЙ ПРОМТ

```
Ты — опытный Python-разработчик, специализирующийся на Telegram-ботах
и автоматизации для малого бизнеса. Ты пишешь минимальный, читаемый,
рабочий код — без лишних абстракций и паттернов. Твои скрипты легко
разворачиваются даже без опыта в программировании, шаги настройки
объясняешь простым языком без технического жаргона.
```

## ОСНОВНОЙ ПРОМТ

```xml
<context>
Я фрилансер. Мне нужно настроить автоматическую отправку запроса на отзыв
для небольшого заведения общественного питания. Когда клиент взаимодействует
с ботом (нажимает кнопку "Я сделал заказ" или "Я здесь"), бот через
{DELAY_HOURS} часов отправляет ему сообщение с просьбой оставить отзыв.
Задача должна быть готова за 1 рабочий день.
</context>

<task>
Напиши три файла:
1. review_bot.py — рабочий Telegram-бот с отложенной отправкой сообщения
2. requirements.txt — список зависимостей
3. setup_guide.md — инструкция по запуску и тексты сообщений

Выведи все три файла подряд, каждый с заголовком вида:
=== ФАЙЛ: название_файла.расширение ===
</task>

<venue_info>
Название заведения: {VENUE_NAME}
Тип заведения: {VENUE_TYPE}
(кафе / ресторан / кофейня / суши-бар / доставка)

Ссылка на 2ГИС для отзыва: {REVIEW_LINK_2GIS}
Ссылка на Google Maps для отзыва: {REVIEW_LINK_GOOGLE}

Задержка перед отправкой: {DELAY_HOURS} часов
Тон сообщения: {MESSAGE_TONE}
(дружелюбный и тёплый / официально-вежливый)

Токен Telegram-бота: {BOT_TOKEN}
(получить у @BotFather — вставить потом, пока оставь заглушку YOUR_BOT_TOKEN_HERE)
</venue_info>

<bot_requirements>

─── ПОВЕДЕНИЕ БОТА ───────────────────────────────────────────────

При команде /start:
- Приветственное сообщение с названием заведения
- Кнопка «✅ Я сделал заказ / посетил заведение»
- Кнопка «📞 Связаться с нами» (опционально, просто заглушка)

После нажатия кнопки «Я посетил»:
- Подтверждение: «Спасибо! Мы пришлём сообщение чуть позже 😊»
- Через {DELAY_HOURS} часов бот отправляет сообщение с запросом отзыва

Сообщение с запросом отзыва должно содержать:
- Тёплое обращение без имени (имя неизвестно)
- Название заведения {VENUE_NAME}
- Ссылки на 2ГИС и Google Maps в виде кнопок под сообщением (InlineKeyboard)
- Короткое и ненавязчивое — максимум 3–4 предложения

─── ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ ──────────────────────────────────────

Библиотека: python-telegram-bot версии 20.x (async, ApplicationBuilder)
Python: 3.10+
Планировщик: встроенный job_queue из python-telegram-bot (не APScheduler)
Хранение данных: простой словарь в памяти (dict) — без базы данных
Токен бота: читается из переменной окружения BOT_TOKEN или из константы вверху файла

Кнопки: InlineKeyboardMarkup (не ReplyKeyboard)
Задержка: {DELAY_HOURS} * 3600 секунд — через job_queue.run_once

─── ANTI-OVER-ENGINEERING ───────────────────────────────────────

Пиши минимальный, читаемый код:
- Один файл review_bot.py, без дополнительных модулей
- Никаких классов, фабрик, абстрактных слоёв — только функции
- Комментарии только там, где логика неочевидна
- Не добавляй функции, которые не были запрошены
- Не делай конфигурационные файлы — все настройки в константах вверху файла

─── СТРУКТУРА review_bot.py ─────────────────────────────────────

Блок 1 — Константы (в самом верху):
  BOT_TOKEN, VENUE_NAME, REVIEW_LINK_2GIS, REVIEW_LINK_GOOGLE,
  DELAY_HOURS, все тексты сообщений как строки-константы

Блок 2 — Обработчики:
  start_handler — /start, приветствие + кнопки
  button_handler — CallbackQueryHandler для кнопки «Я посетил»
  send_review_request — функция отложенной отправки (вызывается job_queue)

Блок 3 — Запуск:
  main() — собирает Application, регистрирует handlers, запускает polling

─── SETUP_GUIDE.MD ──────────────────────────────────────────────

Инструкция должна включать:
1. Как создать бота через @BotFather (2–3 шага)
2. Как установить Python и зависимости (pip install -r requirements.txt)
3. Куда вставить токен (константа BOT_TOKEN в файле)
4. Как запустить: python review_bot.py
5. Как запустить постоянно (краткое упоминание screen/nohup для Linux VPS)

Секция «Тексты сообщений»:
- Полный текст приветственного сообщения (готов к копированию)
- Полный текст запроса на отзыв (готов к копированию)
- Примечание: как изменить тексты (просто заменить константы в файле)

</bot_requirements>

<output_format>
Выведи три блока подряд в формате:

=== ФАЙЛ: review_bot.py ===
[полный код]

=== ФАЙЛ: requirements.txt ===
[зависимости]

=== ФАЙЛ: setup_guide.md ===
[инструкция и тексты]

Никаких пояснений до или после блоков.
Код должен запускаться без изменений после замены BOT_TOKEN на реальный токен.
</output_format>
```

## КАК ЗАПОЛНИТЬ ПЕРЕМЕННЫЕ

### `{MESSAGE_TONE}` — что это меняет

| Тип заведения | Рекомендуемый тон |
|---|---|
| Кофейня, бистро, кафе | `дружелюбный и тёплый` |
| Ресторан среднего класса | `дружелюбный и тёплый` |
| Ресторан премиум / банкетный зал | `официально-вежливый` |
| Суши-бар, фастфуд | `дружелюбный и тёплый` |

### `{BOT_TOKEN}` — где взять

1. Открыть Telegram, найти @BotFather
2. Отправить `/newbot`, придумать имя и username (заканчивается на `bot`)
3. Скопировать токен вида `7123456789:AAGxxxxxxxx`
4. Вставить в константу `BOT_TOKEN` в файле `review_bot.py`

### `{REVIEW_LINK_2GIS}` — как найти

1. Открыть 2ГИС → найти заведение
2. Нажать «Оставить отзыв» → скопировать URL из браузера
3. Формат: `https://go.2gis.com/xxxxx` или `https://astana.2gis.ru/...`

### `{REVIEW_LINK_GOOGLE}` — как найти

1. Найти заведение в Google Maps
2. Кнопка «Оставить отзыв» → скопировать URL
3. Или вручную: `https://g.page/r/xxxxx/review`

## АЛЬТЕРНАТИВА: НО-КОД ЧЕРЕЗ ALBATO (для клиентов без сервера)

Если клиент не хочет разворачивать Python-скрипт — предложи Albato.
Попроси Claude сгенерировать **инструкцию** вместо скрипта:

> «Вместо Python-скрипта напиши пошаговую инструкцию настройки автоматической
> отправки WhatsApp-сообщения через Albato (albato.com). Триггер: новая строка
> в Google Таблице (туда вносит оператор после каждого заказа). Задержка 2 часа.
> Действие: отправка WhatsApp-сообщения через интеграцию Albato + WhatsApp Business.
> Инструкция должна быть в формате "шаг 1, шаг 2..." с конкретными скриншотами-
> описаниями (что нажать, где найти поле).»

**Когда выбирать что:**

| Критерий | Python-бот | Albato |
|---|---|---|
| Стоимость | Бесплатно (кроме VPS ~$3-5/мес) | ~$10-20/мес за Albato |
| Настройка | 30 мин (если есть VPS) | 1 час без кода |
| WhatsApp | Через Telegram (бесплатно) | Нативный WhatsApp Business |
| Клиент должен уметь | Ничего (запустил — работает) | Только вносить строки в таблицу |
| Поддержка | Ты → перезапуск при сбоях | Albato поддерживает сам |

## 🛠 ПРИМЕНЁННЫЕ ТЕХНИКИ

| Техника | Почему применена |
|---|---|
| **Role prompting** | Роль «Python-разработчик для малого бизнеса» важна: без неё Claude может генерировать enterprise-уровень код вместо простого скрипта |
| **Anti-over-engineering** | Официальная документация Anthropic предупреждает: Sonnet 4.6 склонен создавать лишние классы, абстракции и файлы. Явный запрет этого — критичен для кода «на один день» |
| **XML-теги** | 5 тегов разделяют контекст задачи, данные заведения, требования к боту и формат вывода — без них Claude смешивает технические и бизнес-требования |
| **Структура вывода** | Формат `=== ФАЙЛ: ===` вместо markdown-блоков — сигнализирует Claude, что ответ это набор файлов, а не объяснение с кодом внутри |
| **Блок констант** | Требование вынести все настройки в константы вверху файла — делает код понятным для клиента без технических знаний |
| **Альтернативный путь** | Раздел «Albato» — готовый запрос для другого варианта решения (без переписывания промта) |
| **temperature=0** | Для кода нужна детерминированность: при каждом запуске должен получаться одинаковый корректный скрипт |
