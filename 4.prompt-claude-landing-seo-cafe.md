# Промт для Claude: Лендинг + SEO-оптимизация для кафе/ресторана

---

## КАК ИСПОЛЬЗОВАТЬ

1. Скопируй **СИСТЕМНЫЙ ПРОМТ** → вставь в System Prompt (или первым сообщением)
2. Заполни все `{ПЕРЕМЕННЫЕ}` в **ОСНОВНОМ ПРОМТЕ** данными клиента
3. Отправь **ОСНОВНОЙ ПРОМТ** → получи готовый HTML-файл
4. Загрузи на хостинг, подключи домен, замени заглушки фото на реальные снимки

> ⚡ Эта задача сложнее QR-меню: Claude генерирует и код, и все тексты, и SEO.
> Если ответ обрывается — допиши в следующем сообщении: «Продолжай с секции [название]».

---

## СИСТЕМНЫЙ ПРОМТ

```
Ты — опытный веб-разработчик и SEO-копирайтер, специализирующийся на создании
конверсионных лендингов для заведений общественного питания. Ты глубоко понимаешь
принципы локального SEO Google и Яндекс, умеешь писать живые продающие тексты
на русском языке, внедрять ключевые слова органично (без переспама) и генерировать
корректную разметку schema.org для ресторанов. Все создаваемые тобой страницы
отличаются нешаблонным дизайном и убеждают посетителей позвонить или забронировать стол.
```

## ОСНОВНОЙ ПРОМТ

```xml
<task>
Создай полный HTML-лендинг для заведения общественного питания.
Цель страницы — занять позиции в Google/Яндекс по запросам {PRIMARY_KEYWORD} 
и {SECONDARY_KEYWORDS}, а также конвертировать посетителей в звонки и брони.
Итог — один готовый HTML-файл: CSS, JS и schema.org встроены в него.
</task>

<venue_info>
Тип заведения: {VENUE_TYPE}
(варианты: кафе / ресторан / кофейня / банкетный зал / суши-бар / фастфуд)

Название: {VENUE_NAME}
Город: {CITY}
Адрес (точный): {ADDRESS}
Телефон: {PHONE}
Режим работы: {WORKING_HOURS}
Ссылки (Instagram / 2ГИС / Google Maps): {SOCIAL_LINKS}
Домен (или заглушка): {DOMAIN}
Стиль и цвета: {COLOR_STYLE}
</venue_info>

<seo_data>
Главный поисковый запрос: {PRIMARY_KEYWORD}
(пример: «банкетный зал Астана», «лучшая кофейня Алматы», «ресторан центр Шымкента»)

Дополнительные запросы (через запятую): {SECONDARY_KEYWORDS}
(пример: «где отметить день рождения Астана, корпоратив ресторан Астана, 
уютный ресторан с живой музыкой»)
</seo_data>

<unique_selling_points>
{USP_LIST}
(пример:
- Три зала: камерный на 20 чел., банкетный на 80, VIP на 15
- Собственная авторская кухня, шеф с опытом 12 лет
- Бесплатная парковка на 40 мест
- Живая музыка по пятницам и субботам
- Детское меню и уголок для детей
- Доставка по городу за 40 минут)
</unique_selling_points>

<venue_details>
Краткое описание (2–3 предложения о характере и атмосфере): {VENUE_DESCRIPTION}
Тип кухни: {CUISINE_TYPE}
Средний чек: {AVERAGE_CHECK}
Вместимость (если есть): {CAPACITY}
Специальные предложения/акции: {SPECIAL_OFFERS}
</venue_details>

<requirements>

─── SEO В <head> ────────────────────────────────────────────────

- <title>: до 60 символов; включает {PRIMARY_KEYWORD} и {VENUE_NAME}
  Пример: «Банкетный зал Астана — ресторан "Название" | Бронь онлайн»
- <meta name="description">: 145–155 символов; включает {PRIMARY_KEYWORD},
  ключевую выгоду и призыв к действию
- <meta name="keywords">: 8–10 релевантных фраз через запятую
- <link rel="canonical" href="https://{DOMAIN}/">
- Open Graph теги: og:title, og:description, og:type=restaurant, og:locale=ru_RU
- <meta name="viewport" content="width=device-width, initial-scale=1">

─── SCHEMA.ORG JSON-LD В <head> ─────────────────────────────────

Тип: выбери сам по {VENUE_TYPE}:
  кафе/кофейня → CafeOrCoffeeShop
  ресторан/банкет → Restaurant
  фастфуд → FastFoodRestaurant

Обязательные поля:
  @context, @type, name, url, telephone, address (PostalAddress с addressLocality,
  streetAddress, addressCountry: KZ), openingHoursSpecification,
  priceRange, servesCuisine, hasMap (ссылка из {SOCIAL_LINKS})

Дополнительно, если есть банкет:
  amenityFeature: [{ @type: LocationFeatureSpecification,
                     name: "Банкетный зал", value: true }]

─── СТРУКТУРА ЛЕНДИНГА (сверху вниз) ────────────────────────────

1. НАВИГАЦИЯ (sticky, мобильная гамбургер-версия):
   Логотип-текст | О нас | Меню | Банкет | Контакты | Кнопка «Позвонить»

2. HERO-СЕКЦИЯ:
   - H1: содержит {PRIMARY_KEYWORD} дословно или почти дословно
   - Подзаголовок: усиливает H1, упоминает выгоду
   - Формула: «Боль/Желание → Решение → CTA»
   - Две кнопки: «Позвонить сейчас» (tel:{PHONE}) и «Забронировать стол»
   - Фоновый блок: заглушка с комментарием <!-- Фото: главный зал или блюдо -->

3. О НАС:
   - H2 с естественным вхождением {CITY}
   - 2 абзаца живого текста об атмосфере и истории
   - {CITY} упоминается минимум 2 раза в этой секции
   - Маленькие карточки: год открытия, число гостей в месяц, число блюд в меню

4. ПОЧЕМУ МЫ:
   - H2 с ключевым словом
   - 4–6 карточек из {USP_LIST}: emoji-иконка + заголовок + 1 предложение

5. МЕНЮ (превью):
   - H2 с упоминанием типа кухни ({CUISINE_TYPE})
   - 3–4 категории, по 2–3 блюда в каждой с ценой (заглушка если нет данных)
   - Кнопка «Смотреть полное меню» (ссылка на {MENU_LINK} или заглушка #)

6. ФОТОГАЛЕРЕЯ:
   - 6 блоков-заглушек с серым фоном
   - Над каждым <!-- Замените на фото: [описание конкретной сцены] -->
   - Alt для каждого img: '{VENUE_NAME} — [описание сцены], {CITY}'

7. ОТЗЫВЫ:
   - H2 с упоминанием {CITY}
   - 3 реалистичных отзыва: казахстанские имена, 4–5 звёзд, конкретный тематический текст
   - Визуальные звёзды (★★★★★), аватар-заглушка (инициалы)

8. БАНКЕТ / МЕРОПРИЯТИЯ (если тип зала подходит):
   - H2 продающий: «Проведите незабываемое событие в {CITY}»
   - Список форматов: корпоратив, день рождения, свадьба, детский праздник
   - Форма заявки: имя, телефон, дата, кнопка «Оставить заявку»
   - (Форма — только HTML/CSS, без реального бэкенда, с комментарием 
     <!-- Подключите обработчик формы или сервис вроде Formspree -->)

9. КОНТАКТЫ:
   - H2 с {CITY}
   - Адрес, телефон (кликабельный), режим работы
   - Кнопка «Открыть на картах» → ссылка из {SOCIAL_LINKS}
   - Блок под карту: заглушка 400px высотой с комментарием
     <!-- Вставьте iframe с Google Maps или 2ГИС -->

10. ФУТЕР:
    - Копирайт © 2025 {VENUE_NAME}
    - Ссылки на соцсети из {SOCIAL_LINKS}

─── ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ ──────────────────────────────────────

- Один HTML-файл: весь CSS в <style>, весь JS в <script>
- Mobile-first: идеальная работа на 360–430px, корректно на 768px и 1280px
- Шрифт: Google Fonts — Inter (основной) + Playfair Display или Cormorant (заголовки)
- scroll-behavior: smooth; якоря в навигации (#about, #menu, #contacts, #banquet)
- Sticky-шапка: прозрачная на старте → непрозрачная при скролле (JS IntersectionObserver)
- Анимация появления секций при скролле: opacity + translateY (CSS transitions)
- overflow-x: hidden на body — никакого горизонтального скролла
- Изображения: теги <img> с alt; src = короткое имя файла (foto-hall.jpg, foto-dish.jpg)
  и HTML-комментарий ПЕРЕД тегом: <!-- Замените на реальное фото: [описание] -->

─── КОПИРАЙТИНГ ─────────────────────────────────────────────────

- Весь текст на русском языке
- H1 содержит {PRIMARY_KEYWORD} (дословно или с минимальным изменением)
- {CITY} встречается по всей странице минимум 5 раз
- {SECONDARY_KEYWORDS} вписаны в текст органично, без повторений рядом
- Тексты — живые, конкретные, без клише «высококачественный сервис»
  и «мы рады приветствовать вас»
- Hero: формула «[желание/боль читателя] → [решение] → [призыв к действию]»
- О нас: рассказывай историю, упоминай детали (год, команду, особенность)

─── ДИЗАЙН ──────────────────────────────────────────────────────

- Цветовую палитру подбери под {COLOR_STYLE}
- Нестандартный дизайн: не типовой шаблон, декоративные разделители секций,
  геометрические акценты или фактурный паттерн в hero
- Don't hold back on design. Give it your all.
- Apply design principles: hierarchy, contrast, balance, movement
- Add thoughtful details: hover states on cards and buttons, smooth transitions,
  subtle micro-interactions on CTA buttons

─── СТРОГИЕ ОГРАНИЧЕНИЯ ─────────────────────────────────────────

- Никаких «Lorem ipsum» или «Текст здесь» в финальном коде
- Меню — реальные блюда или реалистичные заглушки с ценами, не пустые карточки
- Отзывы — живые тексты с казахстанскими именами, не «Отличное место!»
- Мета-теги заполнены полностью, без плейсхолдеров
- Никаких внешних JS-библиотек (только Google Fonts как CSS)
- Форма заявки — статичная (HTML/CSS только), с комментарием о подключении бэкенда

</requirements>

<output_format>
Верни ТОЛЬКО готовый HTML-файл.
Начни ответ строго с <!DOCTYPE html> — без вводных слов и объяснений.
Изображения — заглушки с HTML-комментариями, описывающими нужный кадр.
Форма заявки — статичная, с комментарием по подключению.
</output_format>
```

## КАК ЗАПОЛНИТЬ ПЕРЕМЕННЫЕ

### `{VENUE_TYPE}` и `{PRIMARY_KEYWORD}` — примеры связок

| Тип заведения | PRIMARY_KEYWORD | SECONDARY_KEYWORDS |
|---|---|---|
| Банкетный зал | банкетный зал Астана | корпоратив ресторан Астана, где провести свадьбу Астана |
| Ресторан | ресторан в центре Алматы | уютный ресторан Алматы, ресторан с живой музыкой |
| Кофейня | кофейня Алматы центр | лучший кофе Алматы, кофейня с завтраком Алматы |
| Суши-бар | суши Астана | доставка роллов Астана, японский ресторан Астана |

### `{USP_LIST}` — шаблон заполнения

```
- Три зала: камерный на 20 человек, банкетный на 80, VIP на 15
- Авторская кухня — шеф-повар с опытом 15 лет в Европе
- Бесплатная парковка на 40 мест рядом со входом
- Живая музыка каждую пятницу и субботу
- Детское меню и игровой уголок
- Доставка по городу за 40 минут или бесплатно
```

### `{COLOR_STYLE}` — примеры

| Заведение | Что писать |
|---|---|
| Классический ресторан | `элегантный ресторан, тёмно-бордовый и золотой` |
| Современная кофейня | `модная кофейня, белый фон, зелёные акценты, матовая минимализм` |
| Банкетный зал люкс | `премиальный зал, чёрный и золото, роскошь` |
| Семейное кафе | `семейное кафе, тёплые бежевый и терракота, уют` |
| Суши-бар | `японский стиль, белый и тёмно-синий, красные акценты` |

### `{DOMAIN}` — если домена ещё нет

Напиши: `nazvanie-cafe.kz` — это будет заглушка в canonical и schema.
Клиент потом поменяет на реальный домен при загрузке сайта.

## ПАРАМЕТРЫ ДЛЯ API (если используешь через API)

| Параметр | Значение |
|---|---|
| `model` | `claude-sonnet-4-6` |
| `max_tokens` | `12000` (лендинг объёмнее QR-меню!) |
| `temperature` | `0.3` (чуть выше 0, для более живых текстов) |
| System prompt | вставить СИСТЕМНЫЙ ПРОМТ выше |

> ⚠️ Если HTML получается длинным и обрывается — добавь второй запрос:
> «Продолжи с секции [название], где остановился»

## РАБОЧИЙ ПРОЦЕСС (2 варианта)

### Вариант A — Одним запросом (рекомендуется для claude.ai)
Заполни все переменные → отправь → получи полный HTML сразу.

### Вариант B — Двумя запросами (если лендинг очень большой)
1. Первый запрос: структура + SEO + hero + о нас + преимущества + меню
2. Второй запрос: «Добавь к этому HTML секции: галерея, отзывы, банкет, контакты, футер» + вставь HTML из первого ответа

## 🛠 ПРИМЕНЁННЫЕ ТЕХНИКИ

| Техника | Почему применена |
|---|---|
| **Role prompting** | Системный промт объединяет ДВЕ роли: разработчик + SEO-копирайтер — это критично, т.к. задача требует обоих навыков одновременно |
| **XML-теги** | 6 блоков (`<task>`, `<venue_info>`, `<seo_data>`, `<unique_selling_points>`, `<venue_details>`, `<requirements>`) — Claude не путает данные с инструкциями |
| **Контекст + мотивация** | В `<task>` объясняется ЦЕЛЬ страницы (трафик + конверсия), а не просто «сделай сайт» — Claude лучше расставляет приоритеты |
| **Frontend encouragement** | Фразы «Don't hold back», «Give it your all», «Apply design principles» из официальной документации Anthropic — они буквально переключают Claude в режим детального дизайна |
| **Чёткий output format** | «Начни с `<!DOCTYPE html>`» вместо prefill — совместимо с Claude Sonnet 4.6 (prefill убрали в 4.6+) |
| **Явные переменные** | Все `{ПЕРЕМЕННЫЕ}` в фигурных скобках, таблица примеров — нет двусмысленности при заполнении |
| **Граничные случаи** | Блок «СТРОГИЕ ОГРАНИЧЕНИЯ» закрывает типичные AI-болячки: Lorem ipsum, пустые отзывы, незаполненные meta |
| **Параметры API** | max_tokens=12000 + temperature=0.3 — выше нуля для живых текстов, но не хаотично |
