# Промт для Claude: Интерактивное QR-меню для кафе/ресторана

---

## КАК ИСПОЛЬЗОВАТЬ

1. Скопируй **СИСТЕМНЫЙ ПРОМТ** и вставь в поле System Prompt (или в начало диалога)
2. Заполни все `{ПЕРЕМЕННЫЕ}` в **ОСНОВНОМ ПРОМТЕ** данными клиента
3. Отправь **ОСНОВНОЙ ПРОМТ** → получи готовый HTML-файл
4. Загрузи HTML на хостинг, сгенерируй QR-код на URL страницы

---

## СИСТЕМНЫЙ ПРОМТ

```
Ты — опытный frontend-разработчик, специализирующийся на создании мобильных
веб-приложений для заведений общественного питания. Твоя задача — создавать
красивые, быстрые и удобные страницы меню, которые идеально открываются на
смартфонах при сканировании QR-кода. Ты пишешь чистый, семантичный HTML с
встроенным CSS и JavaScript — без внешних фреймворков и библиотек (кроме
Google Fonts).
```

---

## ОСНОВНОЙ ПРОМТ

```xml
<task>
Создай одностраничный HTML-сайт интерактивного меню для кафе/ресторана.
Итог — один HTML-файл, полностью готовый к размещению на хостинге.
Весь CSS и JavaScript встроены прямо в HTML.
</task>

<cafe_info>
Название заведения: {CAFE_NAME}
Слоган или короткое описание: {CAFE_DESCRIPTION}
Адрес: {CAFE_ADDRESS}
Телефон: {CAFE_PHONE}
Режим работы: {WORKING_HOURS}
Ссылка (Instagram / 2ГИС / сайт): {CAFE_LINK}
Стиль и цвета: {COLOR_STYLE}
</cafe_info>

<menu_data>
{MENU_DATA}
</menu_data>

<requirements>

СТРУКТУРА СТРАНИЦЫ (сверху вниз):
1. Шапка — название заведения крупно, слоган строчкой ниже, декоративная
   полоска цветом акцента
2. Навигация по категориям — горизонтальный ряд кнопок-тегов с прокруткой,
   при нажатии плавный скролл к нужному разделу; активная категория
   подсвечивается
3. Секции блюд — каждая категория = отдельный раздел с заголовком
4. Карточки блюд — название, цена (крупно), описание (если есть); без фото
   (не запрашивать изображения)
5. Контакты внизу — адрес, телефон, режим работы, кнопка-ссылка
6. Плавающая кнопка "Позвонить" — всегда видна в правом нижнем углу

ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ:
- Один HTML-файл, весь CSS и JS внутри <style> и <script>
- Mobile-first: идеальная работа на экранах 360–430px
- Шрифт подключить через Google Fonts (Inter или Nunito)
- Навигация по категориям — липкая (position: sticky) при скролле
- overflow-x: hidden на body — исключить горизонтальный скролл
- Телефон в контактах — кликабельная ссылка tel:
- Страница без лишних зависимостей, быстрая загрузка

ДИЗАЙН:
- Современный, уютный стиль — не корпоративный, не шаблонный
- Карточки блюд с мягкой тенью (box-shadow) и закруглёнными углами
- Простая CSS-анимация появления карточек при скролле
  (Intersection Observer + классы с transition/opacity)
- Цена — крупно и жирно, цветом акцента
- Цветовую палитру адаптируй под поле {COLOR_STYLE}:
  если указан стиль (например, «уютное кафе, тёплые тона») —
  подобери подходящие цвета самостоятельно

СТРОГИЕ ОГРАНИЧЕНИЯ:
- Никаких заглушек "Lorem ipsum", "Фото блюда", "Описание"
- Никаких внешних JS-библиотек (jQuery, Bootstrap JS и т.д.)
- Если описание блюда пустое — не показывать пустую строку
- Не добавлять пояснений до или после кода

</requirements>

<output_format>
Верни ТОЛЬКО готовый HTML-файл. Начни ответ сразу с <!DOCTYPE html> —
без вводных слов, без объяснений, без блоков markdown с кодом.
</output_format>
```

## КАК ЗАПОЛНИТЬ ПЕРЕМЕННЫЕ

### `{MENU_DATA}` — формат заполнения

Используй этот шаблон для каждой категории:

```
КАТЕГОРИЯ: Горячие блюда
- Паста Карбонара | 2 800 ₸ | Классическая паста с беконом, яйцом и пармезаном
- Стейк Рибай | 7 500 ₸ | Мраморная говядина 250г, гриль, соус демиглас
- Том Ям | 3 200 ₸ |

КАТЕГОРИЯ: Десерты
- Чизкейк Нью-Йорк | 1 500 ₸ | Нежный американский чизкейк с ягодным соусом
- Тирамису | 1 200 ₸ |

КАТЕГОРИЯ: Напитки
- Капучино | 900 ₸ | 300мл, из свежеобжаренного зерна
- Свежевыжатый сок | 1 200 ₸ |
```

Формат строки блюда: `Название | Цена | Описание (можно оставить пустым)`

### `{COLOR_STYLE}` — примеры заполнения

| Тип заведения | Что писать |
|---|---|
| Кофейня, уют | `уютная кофейня, тёплые бежевые и коричневые тона` |
| Современный ресторан | `современный ресторан, тёмный фон, золотые акценты` |
| Детское кафе | `яркое детское кафе, жёлтый и оранжевый` |
| Фастфуд | `быстрая еда, красно-белая гамма, энергичный стиль` |
| Суши-бар | `японский минимализм, белый и чёрный, красные акценты` |

## ПРИМЕНЁННЫЕ ТЕХНИКИ

| Техника | Зачем |
|---|---|
| **Role prompting** | Системный промт задаёт роль эксперта → точнее соблюдает стандарты кода |
| **XML-теги** | Чёткое разделение `<task>`, `<cafe_info>`, `<requirements>`, `<output_format>` → Claude не путает данные с инструкциями |
| **Positive constraints** | «Используй sticky навигацию» вместо «не делай навигацию без sticky» |
| **Explicit output format** | «Начни с `<!DOCTYPE html>`» вместо prefill — совместимо с Claude Sonnet 4.6 |
| **Few-shot example** | Пример формата `{MENU_DATA}` устраняет любую неоднозначность в данных |
| **Clear variables** | Все `{ПЕРЕМЕННЫЕ}` в фигурных скобках — легко найти и заменить |
| **Чёткий запрет edge cases** | Блок «СТРОГИЕ ОГРАНИЧЕНИЯ» закрывает типичные ошибки (заглушки, пустые строки) |
